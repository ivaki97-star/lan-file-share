Models are Easy Model Entities packs: a Blockbench model with its textures and animations, built as one .jar that goes into the mods folder on the server and on every player. Upload the jar (or the zip the Blockbench exporter makes), add skins to it here, and the server admin downloads everything below. Players get the uploaded models through the mods installer, whose pack.json must list this site's model feed.
